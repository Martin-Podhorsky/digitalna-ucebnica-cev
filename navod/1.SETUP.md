# Prvotný setup — Digitálna učebnica CEV

Tento checklist prejdi **raz** pri prvom nastavovaní na novom počítači.  
Už hotové kroky môžeš preskočiť.

---

## ✅ Čo je už hotové
- [x] Cursor je nainštalovaný

---

## 🔧 Krok 1 — Nainštaluj potrebné programy

Otvor **Terminál** (môžeš ho otvoriť priamo v Cursore: `Ctrl + ~`) a spusti postupne tieto príkazy:

### Git
```
winget install --id Git.Git -e --accept-package-agreements --accept-source-agreements
```

### Hugo Extended (generátor webu)
```
winget install --id Hugo.Hugo.Extended -e --accept-package-agreements --accept-source-agreements
```

### Go (potrebný pre Hugo moduly)
```
winget install --id GoLang.Go -e --accept-package-agreements --accept-source-agreements
```

### Node.js (potrebný pre Tailwind CSS)
```
winget install --id OpenJS.NodeJS.LTS -e --accept-package-agreements --accept-source-agreements
```

> ⚠️ Po nainštalovaní všetkých programov **zatvor a znova otvor terminál** (alebo celý Cursor),  
> aby sa programy správne načítali.

### pnpm (správca balíčkov)
```
npm install -g pnpm
```

### Overenie — skontroluj, či všetko funguje
```
git --version
hugo version
go version
node -v
pnpm -v
```
Každý príkaz by mal vypísať číslo verzie (nie chybovú hlášku).

---

## 🔧 Krok 2 — Naklonuj repozitár

Táto časť nahradí stiahnutý ZIP správnou verziou s históriou zmien.

1. Prejdi do priečinka, kde chceš mať projekt (napr. `Dokumenty`):
```
cd "$env:USERPROFILE\Documents"
```

2. Naklonuj repozitár:
```
git clone https://github.com/Martin-Podhorsky/digitalna-ucebnica-cev.git
```

3. Otvor naklonovaný priečinok v Cursore:  
   `File → Open Folder → Documents\digitalna-ucebnica-cev`

> Pôvodný rozbalený ZIP priečinok môžeš potom vymazať — už ho nepotrebuješ.

---

## 🔧 Krok 3 — Nainštaluj závislosti projektu

V termináli (v priečinku projektu) spusti:

```
pnpm install
```
```
hugo mod get -u
```

Toto stiahne všetky potrebné knižnice (Tailwind, téma...).  
Trvá to 1–3 minúty, robí sa **len raz**.

---

## 🔧 Krok 4 — Nastav svoje meno v Gite

Git potrebuje vedieť, kto robí zmeny. Spusti (zmeň meno a email):

```
git config --global user.name "Meno Priezvisko"
```
```
git config --global user.email "tvoj@email.sk"
```

---

## 🔧 Krok 5 — Vytvor si účet na GitHube

**GitHub** je služba, kde je uložený celý zdrojový kód učebnice. Funguje ako „záloha v cloude" — každá zmena, ktorú odošleš, sa tu uloží s históriou. Keď niečo pokazíš, vždy sa dá vrátiť späť.

1. Otvor prehliadač a prejdi na **[github.com](https://github.com)**
2. Klikni na **Sign up** (vpravo hore)
3. Zadaj emailovú adresu, heslo a zvoľ si používateľské meno (napr. `cevucebnica`)
4. Dokonči registráciu a potvrď email

> Po registrácii pošli svoje **používateľské meno** Martinovi — musí ťa pridať ako spolupracovníčku (collaborator) na repozitár, inak nebudeš môcť odosielať zmeny.  
> Až kým ti Martin nepotvrdí, že ťa pridal, **nepokračuj ďalej**.

---

## 🔧 Krok 6 — Prihlás sa do GitHubu v termináli

Tento krok prepojí terminál s tvojím GitHub účtom, aby si mohla posielať zmeny.

```
winget install --id GitHub.cli -e --accept-package-agreements --accept-source-agreements
```

Potom **zatvor a znova otvor terminál**, potom:

```
gh auth login
```

Vyber: `GitHub.com` → `HTTPS` → `Login with a web browser` → skopíruj kód, otvor odkaz, vlož kód a prihlás sa svojím novým účtom.

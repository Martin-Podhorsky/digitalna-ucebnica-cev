# Postup pri úprave a zverejnení zmien

Tento súbor opisuje, čo treba spraviť vždy, keď chceš **upraviť obsah učebnice**  
a zverejniť zmeny na školskom serveri (`cev.eckari.sk`).

---

## 📝 Krok 1 — Uprav obsah

Obsah učebnice sa nachádza v priečinku `content/ucivo/`.  
Každá kapitola je textový súbor `_index.md` v príslušnom priečinku, napríklad:

```
content/ucivo/2-rocnik/01-brzdy/ABS/_index.md
```

Otvor súbor v Cursore a uprav text. Súbory sú písané v **Markdowne** — jednoduchý formát:

```
**tučné písmo**
*kurzíva*
# Nadpis 1. úrovne
## Nadpis 2. úrovne
- odrážka
```

---

## 👁️ Krok 2 — Pozri si zmeny naživo (voliteľné)

Ak chceš vidieť, ako budú zmeny vyzerať pred zverejnením, spusti v termináli (`Ctrl + ~`):

```
pnpm dev
```

Potom otvor v prehliadači: **http://localhost:1313/**  
Stránka sa automaticky obnovuje pri každom uložení súboru.

Keď skončíš prezeranie, zastav server: `Ctrl + C`

---

## 🚀 Krok 3 — Zverejni zmeny

Toto je hlavná časť. Spusti v termináli **jeden príkaz za druhým**:

### 3a) Stiahni najnovšiu verziu (vždy ako prvé!)
```
git pull
```
> Toto zabezpečí, že pracuješ s aktuálnou verziou, nie so starou kópiou.

### 3b) Označ všetky zmeny
```
git add .
```

### 3c) Ulož zmeny s popisom
```
git commit -m "Sem napíš krátky popis, čo si zmenila"
```
Napríklad:
```
git commit -m "Doplnenie kapitoly o pneumatikách"
```

### 3d) Odošli zmeny na GitHub
```
git push
```

---

## ⚙️ Čo sa deje po `git push`

Po odoslaní GitHub **automaticky**:
1. Vygeneruje novú verziu webu pre školský server (`cev.eckari.sk`)
2. Nahrá ju na školský server cez FTP
3. Vygeneruje verziu aj pre GitHub Pages
4. Zverejní ju na `martin-podhorsky.github.io/digitalna-ucebnica-cev/`

Celý proces trvá **1–3 minúty**.

Priebeh môžeš sledovať na:  
`https://github.com/Martin-Podhorsky/digitalna-ucebnica-cev/actions`

Zelená fajka ✅ = všetko prebehlo správne  
Červený krížik ❌ = niečo zlyhalo (kontaktuj Martina)

---

## ⚠️ Časté problémy

**`git push` sa pýta na meno a heslo**  
→ Spusti `gh auth login` a prihlás sa (postup v `SETUP.md`, Krok 5).

**Chyba `rejected` alebo `conflict` pri `git push`**  
→ Najprv spusti `git pull` a potom znova `git push`.

**`pnpm dev` nefunguje / stránka sa nezobrazuje**  
→ Skontroluj, či si v správnom priečinku (`digitalna-ucebnica-cev`).  
→ Skús: `pnpm install` a potom znova `pnpm dev`.
